# 2026-09-19 来源管理与共享域名修正

## 最终采用方案

- TikTok/抖音继续以blackmatrix7固定基线为主，保留人工补充与排除，发布条数仍为22/9。
- Semporia仅作已归档对照；未采用宽泛关键词、User-Agent，也未按旧列表删除原有接口域名。
- 26个服务列表与此前发布版逐字相同。仅Priority新增 `host-suffix, snssdk.com, direct`，优先于GlobalMedia中的同域名规则；保留其余340条具体例外。
- 新增来源维护表：48个来源地址核验、26个服务首选/备选及Priority维护方法。
- 私人v5/v6/v7、mono节点文件、Kuromis、DNS、MITM、脚本与策略组选项均不改动。

## 验证与风险

静态验证包括规则语法/去重/策略引用、域名/关键词/模拟UA回归、对照源未混入发布、图标映射和敏感值扫描。
snssdk.com为共享域名，国内优先是明确取舍，不代表全部请求仅属于抖音；TikTok相关请求可能受此影响，须在手机核验。
本次没有验证真实节点、登录或播放，也没有自动更新手机资源。

## 手机使用

无需换配置。在圈叉分流资源中更新OX-Priority即可；更新全部分流资源也可。
确认Priority仍排在普通服务资源之前且无force-policy。分别测试抖音/TikTok并查看请求记录。
如出现问题，可通过新Git提交撤回该人工例外并重新构建；不要直接编辑生成文件或强制改写历史。
